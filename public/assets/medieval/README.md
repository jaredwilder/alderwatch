# Alderwatch curated medieval assets

This directory is populated by `npm run assets:medieval` / `scripts/fetch_medieval.mjs`.

## Source

Quaternius — **Medieval Village MegaKit**, Standard/free edition.

- Author: Quaternius
- Original pack: https://quaternius.com/packs/medievalvillagemegakit.html
- License: **CC0 1.0 Universal / Public Domain Dedication**
- Commercial use: permitted by the author under CC0
- Browser conversion mirror pinned by commit: `jm-sky/seedvale@9e69e3d8898f8105d06ceac92c95981482810163`
- Mirror license receipt: `docs/assets/quaternius-medieval-village-megakit-license.txt` in that pinned repository

The pinned mirror converted the original free glTF assets to optimized self-contained GLB files (512px WebP textures + gltfpack compression). Alderwatch fetches only the twelve pieces actually used by the village shell and dressing instead of shipping the 300+ piece pack.

## Curated set

Architecture: plaster straight/door/window wall modules, dark-wood door frame and leaf, window insert, exterior timber corner, 6×6 round-tile roof, chimney.

Dressing: crate, wagon, wooden fence.

The authored shell follows Alderwatch's existing 6×6 m longhouse footprint. Existing gameplay collision, building mechanics and save data remain authoritative; these assets are presentation only.
